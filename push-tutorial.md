# Turn on Scrubber Duckies notifications

This sends the notification sender to your Firebase project. It takes about 5 minutes.

## Run it

Tap the **copy to Cloud Shell** button on the right of the line below (it puts the command in the terminal), then tap the terminal and press **Enter**:

```bash
bash scripts/deploy-push.sh
```

If you can't see a button, tap into the terminal and type it yourself: `bash scripts/deploy-push.sh`

**If it asks you to sign in:** open the link it shows, sign in with your Google account, copy the code and paste it into the terminal (tap the terminal, then press and hold and choose **Paste**).

Wait for **✅ All done!**

## Then on each phone

Open Scrubber Duckies from the home-screen icon, then go to **Pond → Notifications → Turn on notifications** and tap **Allow**.
